# ブレイン脱獄（数学ゲーム）

中3向けの数学受験対策 PWA。ターン制タワーディフェンス × 脱獄ストーリー。
問題を解く＝1ターン。正解でコインとこうげき、不正解で看守が1歩進む（時間制限なし）。

- iPhone Safari 向け・縦画面・ビルド不要の静的ファイル（HTML/CSS/JS）
- オフラインで動く（Service Worker）。外部サーバー・外部API・アクセス解析なし
- データは端末内（localStorage）だけ。バックアップの書き出し／読み込みあり
- 入力はニックネームだけ

## 中身

| 範囲 | 単元 |
|---|---|
| 第1段階（入口・診断の対象） | 正負の数／分数・小数の計算／文字式／一次方程式 |
| 第2段階（メイン） | 式の計算／**連立方程式**／展開と因数分解／平方根／**二次方程式** |
| 第3段階（枠とロック表示のみ） | 比例・反比例、一次関数、関数 y=ax²、図形各種、空間図形、確率、データ、文章題の総合 |

遊びの流れ: 初回の **看守チェック（診断）** → つまずいた単元は **訓練（ステップ解説・スキップ不可）** → **練習ウェーブ** → **ボスウェーブ** → まちがえた問題は **リベンジおばけ** として後のウェーブに再襲来（2回正解で卒業）。

## フォルダ構成

```
index.html / manifest.webmanifest / sw.js   アプリ本体の入口
css/app.css                                  見た目
js/main.js                                   起動
js/core/      数の計算（分数・平方根・多項式）、数式表示、保存、効果音 など
js/units/     単元データ（1単元 = 1ファイル）と registry.js（単元の登録所）
js/game/      ゲームのしくみ（engine.js = ターン制TD本体）、キャラ、ミッション、報酬
js/screens/   画面（ホーム、マップ、診断、訓練、バトル、結果、コレクション、記録、設定）
js/ui/        盤面・解答入力（テンキー）の部品
icons/        ホーム画面用アイコン
tests/        検算テスト（公開しなくてよい）
tools/        アイコン生成・SW更新・ローカル確認用サーバー（公開しなくてよい）
docs/         単元のひな型
data/         過去問の追加方法
```

## 1. GitHub Pages で公開する手順（はじめての人向け）

> 用意するもの: パソコン（Chrome か Edge）、メールアドレス

1. https://github.com を開いて **Sign up** でアカウントを作る（無料）。
2. ログインしたら、右上の **＋** → **New repository** を押す。
3. **Repository name** に好きな名前を入れる（例: `brain-escape`）。
4. **Public** を選ぶ（無料プランで GitHub Pages を使うには Public が必要。アプリのプログラムは誰でも見られる状態になるが、個人情報は入っていない。遊んだ記録は各自のスマホの中だけに保存されるので公開されない）。
5. 下の **Create repository** を押す。
6. 次の画面の **uploading an existing file** というリンクを押す。
7. エクスプローラーで `E:\math-escape` を開き、次のものを **まとめてブラウザの画面にドラッグ＆ドロップ** する:
   - `index.html`、`manifest.webmanifest`、`sw.js`
   - `css`、`js`、`icons` フォルダ（フォルダごとドラッグしてOK）
   - （`tests`、`tools`、`docs`、`data`、`README.md` は入れても入れなくてもよい）
8. アップロードが終わったら、下の **Commit changes** を押す。
9. 上のメニューの **Settings** → 左のメニューの **Pages** を開く。
10. **Build and deployment** の **Source** を **Deploy from a branch** にし、**Branch** を `main`、フォルダを `/ (root)` にして **Save**。
11. 1〜3分待ってページを再読み込みすると、上に **Your site is live at https://（ユーザー名）.github.io/brain-escape/** と出る。これがアプリのURL。

### アプリを更新するとき

1. パソコンで `node tools/update-sw.mjs` を実行（sw.js のファイル一覧と版番号が更新される。これを忘れると iPhone に新しい版が届かない）。
2. GitHub のリポジトリ画面で **Add file → Upload files** から、変えたファイル（と `sw.js`）を同じようにドラッグして **Commit changes**。
3. iPhone ではアプリを開いて一度閉じ、もう一度開くと新しい版になる。

（git を使える場合は、このフォルダはすでに git リポジトリになっているので
`git remote add origin https://github.com/ユーザー名/brain-escape.git` → `git push -u origin main` でもOK）

## 2. iPhone で「ホーム画面に追加」する手順

1. iPhone の **Safari** で、上の手順で出たURL（`https://ユーザー名.github.io/brain-escape/`）を開く。
   - Chrome など他のブラウザではなく、**Safari** で開くこと。
2. 一度タイトル画面が出るまで待つ（このときオフライン用にアプリが保存される）。
3. 画面下の **共有ボタン（□に↑のマーク）** を押す。
4. メニューを下にスクロールして **ホーム画面に追加** を押す。
5. 名前が「ブレイン脱獄」になっているのを確認して、右上の **追加** を押す。
6. ホーム画面にできたアイコンから開く。全画面のアプリとして動き、機内モードでも遊べる。

注意:
- **ホーム画面のアイコンから遊ぶこと。** iPhone では「Safari で開いたページ」と「ホーム画面のアプリ」は記録が別々に保存されます。
- 記録はそのiPhoneの中だけにあります。機種変更や設定のリセットに備えて、ときどき **設定 → バックアップ → ファイルに保存**（「"ファイル"に保存」を選ぶ）をしておくと安心です。復元は **設定 → ファイルから復元**。

## 3. 問題（単元）を追加する方法

問題はすべてプログラムで作られ、**答えもプログラムで計算**します。さらに `tests/verify.mjs` が、画面に表示する式そのものを別の方法で計算し直して、答えが正しいか・選択肢に正解が1つだけあるか・数がきれいか を自動チェックします。

### 新しい単元を作る（第3段階など）

1. `docs/unit-template.js` を `js/units/stage3/（単元名）.js` にコピーする。
2. 中身を書きかえる:
   - `generators` … 問題を作る関数（「先に答えを決めてから問題を作る」と答えがきれいになる）
   - `lessons` … 訓練のステップ（1ステップ = 1操作。`q` を付けたステップは正解しないと進めない）
   - `hintCard` … 思い出しカードの要点
   - `prereqs` … この単元を開けるのに必要な単元
3. `js/units/registry.js` に `import` を1行、`UNITS` の並びに1行追加。
   `js/units/stage3/placeholders.js` にある同じ単元の「工事中」の行は消す。
4. テストを実行して、全部 ✓ になるまで直す:
   ```
   node tests/verify.mjs
   ```
5. `node tools/update-sw.mjs` を実行してから公開（上の「アプリを更新するとき」）。

### 既存の単元に問題の型を足す

単元ファイルの `generators` に関数を1つ足し、どれかの訓練の `unlocks` に名前を入れるだけ。テストが自動で500問ずつ検算します。

### 過去問を足す

`data/past-exams/README.md` を見てください（単元ファイルの `pastExams` に書くと、ボスウェーブに出ます）。

## 4. キャラ・タワーの画像を入れる（任意）

画像が無いあいだは絵文字で表示されます。ChatGPT 用のプロンプトは `docs/image-prompts.md`。

1. できた画像（PNG）を、表のファイル名にリネームして `art-src\` フォルダに入れる
2. `node tools/import-art.mjs` を実行（256×256 に縮小して `art\` に保存し、自動で組みこむ）
3. 背景が透明でない画像は警告が出るので、ChatGPT に作り直してもらう
4. いつもどおり公開（`art\` フォルダもアップロードする。`art-src\` は不要）

## 5. パソコンで動作確認する

```
node tools/serve.mjs
```
→ ブラウザで http://localhost:8787 を開く（開発中はキャッシュが邪魔なので Service Worker は止めてある。試すときは http://localhost:8787/?sw ）。

```
node tests/verify.mjs
```
→ 全単元の問題生成器を各500問ずつ検算、訓練の小問、ゲームバランスのシミュレーション、保存とバックアップ、オフライン対応、外部通信がないこと をまとめてチェック。

## プライバシー

- 送信するコードは含まれていません（`fetch` や外部URLが無いこともテストで確認）。
- 保存されるのは、ニックネーム・解いた問題の記録・ゲームの進み具合だけ。本名・学校名・連絡先は扱いません。
