# 過去問の追加方法

過去問は「固定の問題」として、各単元ファイルの `pastExams` に書きます。
登録すると、その単元の **ボスウェーブ** に混ざって出題されます（タグに出典が表示されます）。

```js
// 例: js/units/stage2/simultaneous.js の export default の中
pastExams: [
  {
    id: 'shiga-2025-1-4',           // 重ならない id（県-年-大問-小問 など）
    origin: '滋賀県 2025 大問1(4)',   // 出典（画面に表示される）
    difficulty: 3,
    problem: () => ({
      stem: '連立方程式を解け。 $\\sys{2x+3y=7}{x-y=1}$',
      ...numAns([['x', 'x'], ['y', 'y']], { x: 2, y: 1 }),
      hint: '加減法か代入法で。',
      steps: ['②×3 + ① で $y$ を消す', '$x=2,\\ y=1$'],
      check: { kind: 'equations', eqs: ['2x+3y=7', 'x-y=1'] },
    }),
  },
],
```

- 大問を小問ごとに分けて、1問ずつ登録してください。
- 単元が複数にまたがる問題は、いちばん中心になる単元に入れます。
- `check` を必ず書くこと。`node tests/verify.mjs` が答えを検算し、間違っていればテストが失敗します。
- 図が必要な問題（図形など）は、今の表示機能では出せないので、文章で表せるものに限ります。
- 入試問題の著作権に注意。家庭内で使う範囲にとどめ、公開リポジトリに問題文をそのまま載せないでください（GitHub Pages で公開する場合は、問題を数値だけ変えた「類題」にするのがおすすめ）。
