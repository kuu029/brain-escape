# ChatGPT 用 画像プロンプト（ブレイン脱獄）

## 作り方のコツ（大事）

1. **1つのチャットで続けて作る**と画風がそろいます。最初に下の「共通スタイル」を送ってから、1枚ずつ頼んでください。
2. 2枚目以降は「さっきと同じ画風・同じ線の太さ・同じ塗り方で」と毎回つけると安定します。
3. 出来上がったら **PNG のままダウンロード**し、下の「ファイル名」にリネームして `E:\math-escape\art-src\` に入れてください。
   そのあと `node tools/import-art.mjs` を実行すると、256×256 に縮小して自動で組みこまれます（背景が透明でない画像は警告が出ます）。
   画像がまだ無いものは絵文字のまま動くので、1枚ずつ足していってOK。
4. 気に入らなければ「もっと〇〇に」と何回でも直してOK。**背景が透明になっているか**だけは必ず確認してください（背景が白・市松模様の絵として描かれていたら「背景を本当に透明にして」と頼み直し）。

---

## 共通スタイル（最初に1回送る）

```
これから、スマホのタワーディフェンスゲーム用のキャラクター画像を何枚も作ってもらいます。全部の画像で次のルールを守ってください。

・正方形 1024×1024、背景は完全に透明な PNG
・画風：太めの濃い紫〜黒のアウトライン、フラットな塗り＋やわらかい陰影1段、彩度高めのポップな色
・雰囲気：ちょっとおバカでクセになる「ミーム系」のオリジナルキャラ。日用品や食べ物に目や手足がついたような、ゆるくてシュールなデザイン。既存のゲーム・アニメ・ネットミームのキャラクターには似せない
・構図：やや上から見下ろした斜め45度、全身が入る、キャラを中央に置いて上下左右に10%の余白
・文字、数字、ロゴ、背景、床、地面の影は入れない
・小さく表示（約70ピクセル）しても形がわかるよう、シルエットをはっきり、細かい模様は少なめ
まずは了解とだけ返事してください。
```
